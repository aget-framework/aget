# Constraint sources and limits

Edition: October 12, 2026. Explanatory follow-up for readers, builders and maintainers using the accepted October 8 model. This table does not adopt new requirements, change the model, or certify runtime enforcement.

Population: all twelve entries in the [published model’s constraint register](https://github.com/aget-framework/aget/blob/e22fe248ad0bfd822beae1e3c01ef35c8afe47e7/docs/architecture/grounded-views-2026-10-08/accepted-draft/public-model.json). Four entries contain direct public-support links; eight contain empty public-support lists. Some of the latter can be understood from other public model fields. Neither link presence nor a model self-description proves that an independent governing rule entails the exact condition.

The table separates the condition from its public rationale and limits. Original private decision records and internal instructions are not reproduced here. Where the public package lacks an exact governing source, that gap remains explicit.

## Maintenance

The framework maintainer owns this map under continuing publication stewardship. Review it when a supporting source or meaning changes, before a substantive model revision, or before using an affected condition as normative or runtime proof. Resolve each missing public source with an accessible governing reference or a scoped, authorized public rationale; otherwise retain the limitation. Report discrepancies through the [public issue tracker](https://github.com/aget-framework/aget/issues).

This follow-up is not part of the v3.36.0 tagged source tree. Numbered-release applicability is not established; the maintainer must assess it before an affected applicability claim. The accepted-draft model and its historical reported test results remain unchanged.
