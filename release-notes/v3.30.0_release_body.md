**Theme**: Portable Skills, Continuous Cadence

v3.30.0 turns an existing skill subset into a bounded, digest-addressed package with executable conformance and a documented manual cross-client path.

## What's New

- Added a manifest that binds packaged skill names, paths, sources, and SHA-256 digests.
- Added executable validation for manifest shape, path containment, identity, digest integrity, and frontmatter.
- Added a documented manual copy-and-invoke path for compatible Agent Skills clients.
- Clarified that hooks, permissions, release gates, and structural enforcement do not travel with the package.
- Published both value-gate views: 37/49 planned functional SU and 5/8 landed functional and capability SU.

## Compatibility

No breaking changes. Existing Claude and Agent Skills paths remain supported; marketplace registration, automatic installation, and equivalent client governance are not claimed.

## Migration

- Pin v3.30.0, run `python3 scripts/validate_agent_skill_package.py`, then follow the documented manual path.
- Require an independent downstream receipt before treating public availability as delivered use.
