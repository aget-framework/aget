# v3.30.0 — Portable Skills, Continuous Cadence

**Prepared**: 2026-08-09 · **Type**: minor · **State**: RELEASED

> v3.30 turns an already-present skill subset into a bounded, digest-addressed package that can be
> checked and moved through a documented manual path. It does not claim marketplace availability,
> automatic installation, or portable enforcement.

The immutable `v3.30.0` tag contains the pre-publication `RELEASE CANDIDATE` label. Mutable `main`
records the released state and post-tag corrections; the tag remains immutable.

## Why this release

The three session skills exposed in v3.29 were source artifacts, not a distribution contract. A consumer
had no package manifest binding names, paths, sources, and digests; no conformance command; and no precise
statement of which controls would be lost when the skills moved to another client. v3.30 supplies that
missing release vehicle while preserving the weekly cadence.

## What changed

- **Bounded package inventory**: `AGENT_SKILLS_PACKAGE.json` names `aget-wake-up`, `aget-study-topic`,
  and `aget-save-state`, binds each package path to its canonical source, and records its SHA-256 digest.
- **Executable conformance**: `scripts/validate_agent_skill_package.py` checks manifest shape, repository
  path containment, source/package identity, digest integrity, and the current Agent Skills frontmatter
  contract. The focused suite includes positive and negative controls.
- **Manual cross-client path**: `docs/AGENT_SKILLS_PACKAGE.md` documents verification, resolved copying,
  and one packaged-skill invocation without promising an installer.
- **Truthful enforcement boundary**: the package carries model-followed skill instructions. Hooks,
  permissions, release gates, and D71-style structural enforcement do not travel with it.
- **Frontmatter coherence**: the packaged wake-up skill uses scalar `allowed-tools`; study-topic moves its
  version marker under string-to-string `metadata`.

The three skill instruction bodies were already present in the v3.29.0 tag and receive no new delivery
credit in this release.

## Verify and use

```bash
python3 scripts/validate_agent_skill_package.py
```

Exit `0` validates the bounded package. Then follow `docs/AGENT_SKILLS_PACKAGE.md` to copy a resolved skill
directory into a compatible client's documented skill location and invoke it manually.

## Breaking changes

None. Existing `.claude/skills` and `.agents/skills` paths remain. The frontmatter corrections remove
unsupported shapes without changing the skills' documented tasks.

## Rollback

Revert the v3.30 release commit or restore the v3.29 tag. The package adds no registry state, installer,
data migration, or destructive conversion. Consumers that manually copied a skill may remove that copied
directory independently.

## Known boundaries

- The package is not registered in a marketplace and has no one-command installer.
- The package is client-format portable, not substrate-free: its instructions require receiver-local AGET
  scripts and repository paths that the package does not carry or digest-bind.
- A conformance PASS proves package integrity and format, not client discovery or equivalent governance.
- The bounded downstream Gate-4 receipt is complete. It does not prove full-version or fleet convergence.
- Fleet migration must follow `handoffs/FLEET_MIGRATION_CONTRACT_v3.30.0.json`; neither the six-file
  bounded package nor all 38 tag-delta files is the fleet payload by itself.
