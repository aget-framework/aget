**Theme**: Repair release truth and reduce principal decision work

v3.29.0 separates producer, publication, received-state, and downstream-behavior evidence while making the release decision visible in one governed view with explicit ordinary-use proof.

## What's New

- Added Codex-native discovery for wake-up, study-topic, and save-state, with explicit recovery behavior.
- Added executable Claude Code and Codex CLI control-conformance evidence across five dimensions.
- Added a one-view release decision renderer with zero-join acceptance criteria.
- Made study-topic purpose weighting effective and disclosed recency, searched surfaces, and omissions.
- Added instruction-reach checks that preserve operative governance through root decomposition.
- Made release distribution evidence require four independent predicates instead of inferring delivery from publication.

## Compatibility

No breaking changes. Supported-client conformance covers Claude Code and Codex CLI only.

Literal `/aget-*` compatibility is not included in v3.29.0 and remains planned for v3.30.

## Migration

- Pin the v3.29.0 core/template tag, preserve instance-owned extensions, and run the receiving seat's baseline comparison.
- Prove downstream Codex discovery, invocation, and recovery separately from version receipt.
